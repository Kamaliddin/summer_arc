# Restaurant Dashboard
AI-powered restaurant analytics with employee gamification.

## Features
- Real-time revenue tracking vs daily targets
- Employee level system (Newcomer → Legend)
- Owner alerts for low staff ratings
- Per-day target setting with special day override
- SQLite database for persistent data

## Tech
Python, Streamlit, SQLite, Matplotlib

## Run locally
pip install streamlit matplotlib
streamlit run week4_restaurant_dashboard.py
